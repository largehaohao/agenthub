# AgentHub

AgentHub is a desktop-first local control center for managing multiple coding-agent sessions.

The current implementation target is a native macOS app backed by a persistent local daemon. See the approved design and delivery plans under `docs/superpowers/`.

## Development prerequisites

- macOS 14 or newer
- Xcode 16 or newer with Swift 6
- XcodeGen 2.45.4 or newer

Run the baseline verification with:

```bash
./scripts/check.sh
```
